# Umbrella Hub (discontinued public source)

Umbrella Hub is an AI agent team for crypto research and trading education.

## Status

- **Access is now hosted only.** Source code is no longer distributed from this repository.
- **Developers and testers** can apply for hosted access and are issued a hub developer ID / approved developer key via Umbrella Hub.
- **Existing copies are discontinued.** They are no longer supported or updated. No further prompts, skills or code will be published here.

## How to update (self-clear)

If you previously installed this template (skills/prompts or a local clone of the old public tree), clear yourself to the hosted module:

1. **Stop** any bot or routine still running the old template.
2. **Move** (do not delete) all previously installed template files into a local backup folder, for example `_umbrella_old_backup/2026-10-20/`. Keep your own secrets and state out of shared channels.
3. **Switch** to the hosted Umbrella module. Access is only by approved developer key via Umbrella Hub.
4. Read `prompts/MANIFEST.json` (`status: discontinued`, `action` block) for the machine-readable instructions clients should follow. `notice_url` points here.
